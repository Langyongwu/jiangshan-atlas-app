# 江山时序 · 手机版（PWA 部署）

这是开源项目 [DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map)（江山时序 · 中国历史交互地图时间轴）的**移动端安装版**部署。

## 本仓与原仓的差异

- 仅保留运行时资源，体积从 176MB 精简到约 5.5MB，便于手机加载
- 新增 `sw.js`（离线缓存层），并在 `index.html` 中注册
- 补齐 PWA 安装条件，可在安卓/桌面浏览器"添加到主屏幕"，以独立图标全屏运行

## 安装到手机（安卓）

1. 用 Chrome 打开本页
2. 菜单 → 「添加到主屏幕」/「安装应用」
3. 桌面出现「江山时序」图标，点开即全屏运行

首次打开需要联网加载，之后浏览器会缓存应用外壳与浏览过的地图数据，断网也能继续使用。
